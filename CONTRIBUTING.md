# Contributing to CRC Practice Manager

- Open an issue describing the problem and acceptance criteria before significant changes.
- Fork, create a focused branch, and submit a pull request to main.
- Include tests and document schema migration, rollback, compatibility and security implications. Use only synthetic fixtures.
- Never include client records, real employee details, project files, financial data, credentials, production databases, proprietary templates or confidential business policies.
- Document the origin, version, license and redistribution compatibility of third-party dependencies. Do not copy Manager.io source into the project.
- Submit only contributions you have the right to license under Apache-2.0.
- Follow verified build instructions and pass required CI checks once available.

Maintainers decide what is merged. Public contributions do not confer production access.
