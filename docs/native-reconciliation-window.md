# Native reconciliation window
The new development-only action in Accounting connection opens a separate window for eight independently entered summary amounts and explicit operator confirmation of single currency and zero opening balances. No expected values are prefilled. Existing directory permissions, enrolled marker, profile revision, current session and role mappings are required, and rechecked after acquisition. Only the exact test business and test roles are accepted. Inputs are held in memory; no Manager writes, no CRC financial writes or posting. A mismatch is not success. Build and UI interaction are separate: no local executable acceptance until distribution hold cleared. Source changes only.
