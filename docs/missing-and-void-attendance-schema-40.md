# Missing and erroneous attendance sessions — proposed schema 40

Dependent on schema 39 candidate 6a1f1b3. Complete attendance exception handling without pretending that a reconstructed interval was observed by the clock.

- Independently authorized Work.Correct + Work.Review and employee/project/client view grants. Manager records a verified completely missed, positive, nonoverlapping UTC-second interval for a known employee (including former staff); explicit evidence, confirmation and unique operation key, normalized exact retry, actor binding. Never self record. Origin Manual, distinct from Clock; record original entered interval, author, evidence, UTC recording date. No fake raw clock events, no automatic approval of time or cost.
- Independent manager may void demonstrably erroneous or duplicate closed attendance with mandatory reason, confirmation, exact latest correction ID, immutable evidence. Never delete, change actual work, or use void to discard valid earned time. Open sessions require missed clock-out recovery first. Void terminal; new verified interval is separate manual record with new operation key. No automatic restoration or payroll changes. Same independent manager may correct or void their own manual recording for another employee; not their own attendance.
- Historical view retains all originals, corrections and voids with explicit source/status. Effective nonvoid view alone drives open clock and overlap controls. Manager history exposes recorded reason/actor/time; employee sees source/status only. Database guards preserve origin and void evidence, protect raw insert and close, reject stale revisions, overlap and self-recording. Atomic audit, concurrency, rollback, direct SQL, migration and restore qualification. No payroll inference or external posting.
- Test-first stubs intentionally fail; full Windows green required after schema 39 qualification. No main merge, production data or executable distribution.

Candidate implementation: source-tagged immutable attendance origin fields, separate immutable void evidence, all-history and effective nonvoid views. Manual records use closed intervals with independent evidence; clock-origin insert restrictions retained. Employee and reviewer UI distinguishes source and void state. Added audit rollback, concurrent idempotence and direct SQL regression. No external settlement or payroll changes. Exact Windows and desktop acceptance still required.
