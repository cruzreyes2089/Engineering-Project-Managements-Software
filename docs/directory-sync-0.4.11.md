# v0.4.11 — local customer synchronization and provisional roles

Schema 6 adds an administrator-seeded Directory.Sync grant, per-user/per-profile-revision local directory scopes tied to the enrolled marker, directory rows and provisional account roles. Back up closed schema-5 database before upgrade. Never modify existing CRM clients or contacts; no Manager writes. Explicit sync reads at most 200 customers across at most ten pages per sweep, requires two identical complete sets and marker checks before and after, and commits all updates in one local transaction. Retain missing customers with present=false; show count of missing linked customers, including those never observed. No auto-link by name. Snapshot cache can be viewed locally after restart with current profile/marker and permissions; it is explicitly stale until re-synced. A replacement profile cannot reuse its predecessor's snapshot or roles. Clone/restore risks remain.

Provisional roles ServiceIncome and OfficeExpense are chosen manually from validated live chart-of-accounts, with a second live fetch on save, and uniqueness enforced within scope. Account type is NOT verified by the list API; selection requires human confirmation and cannot be used for posting. Cached role labels may become stale; no production account mapping claim. Remove changes only local role assignment. No background sync, no customer creation in Manager, no invoice posting, no ledger reconciliation. Financial preview from v0.4.10 included. Owner acceptance: financial fixture comparison, directory sync repeat and restart, two role assignments, duplicate rejection, remove/reassign, preserved CRM and Manager test records.
