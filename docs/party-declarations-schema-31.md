# Project participant declarations — schema 31

Restricted manually reviewed signed-PDF evidence is linked to exact registered project party and document identity, with immutable decision and review history. Architects, designers and contractors require a current ReviewedNoConflict declaration before project clearance; any active party's recorded concern, unverified or superseded declaration also holds clearance. This is a conservative development policy, not a legal opinion or proof of coverage. Parties and declarations increment the evidence revision; new project screening must explicitly reference it. Historical clearance remains recorded but new work/start/additional scope uses the current gated view. Superseding a declaration PDF immediately invalidates clearance. Existing projects with no registered parties are not retroactively assigned invented declarations. Does not validate signatures, identify unregistered participants, establish completeness of the party list, or automate pre-proposal declaration collection. Approved declaration form language and employer-specific requirements remain subject to owner/counsel review. No automatic release or deletion. Tests exercise missing, stale, superseded and concerning evidence. Documents remain restricted; status alone is visible under project permissions.
