# Reporting center usability

Choose a project by number, title and client. Date inputs are labeled; the single available project may be suggested. Generate only the selected report, not unrelated financial or operational reports. Project performance, all-date closeout and financial preview have separate tabs. Financial preview is shown only when the existing service's financial, invoice-view and rate grants are available. Firm time summary remains independently available. Closeout disables date fields and keeps the explicit close/reopen action in its own context. Changing project, date or tab clears stale output. Report content and calculations are unchanged; no posted revenue, AR, profit, payroll or new accounting authority is inferred. No schema changes. Exact CI and interactive acceptance pending.
