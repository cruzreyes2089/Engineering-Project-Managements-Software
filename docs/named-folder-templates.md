# Named production template catalog — schema 50

CRC Engineering is an explicit read-only preset; businesses can copy it, copy their previously saved flat layout, or start with an empty editor and save multiple named templates. The UI supports nested relative paths up to four levels, parent-first exact spelling, 1–60 directories, case-insensitive uniqueness, and safe components. Named revisions are append-only. The project selection dialog requires explicit selection and confirmation, binds the exact revision and optional correspondence choice, and retains selection history. New catalog revisions do not silently change previously selected projects. A stale catalog choice or stale project selection is rejected. Unassigned projects retain their old preview as a clearly labeled suggestion, never a saved assignment. Restricted folders remain a fixed separate permission boundary.

The current implementation permits explicitly replacing a logical selection because no actual provisioning exists. Physical directory creation remains disabled; later activation must bind approved storage identities and prevent implicit relocation. The old flat editor is retained as a compatibility preview suggestion, not a required business default. Per-project ad hoc path overrides and automatic project-type rules are not yet implemented. Existing schema 49 preferences remain untouched, no automatic migration into named catalog; the copy action enables explicit adoption. All named template and selection records belong to the single business database. No release approval. Exact revision CI pending.
