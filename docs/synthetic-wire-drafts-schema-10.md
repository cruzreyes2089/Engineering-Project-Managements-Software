# Schema 10 — persistent synthetic full-wire drafts

The accepted PowerShell experiment validates the proposed form shape and correlation references. Schema 10 adds a local, separately permissioned queue for complete synthetic wire intents and exact canonical JSON, with an immutable payload fingerprint and stable operation reference. It reconstructs stored intents after restart and checks the compiled JSON/hash before approval, inspection or cancellation. Legacy rehearsal keys cannot be reused; no migration or promotion of old rehearsal approvals. Database triggers reinforce source-key collision prevention, payload immutability, retained history and allowed transitions. Preparation and approval are explicit, separately granted and audited; same-owner approval is allowed for this synthetic exercise only. Approval remains tied to the reviewed hash, with current approver grant checked during inspection. Approved but unsent drafts may be cancelled only with approval permission. Cancelled keys are retained.

Scope remains the existing offline rehearsal fixture, not the accepted live native-write business. There is no dispatch method, actual posted state, external GUID mapping, credential or witness integration in this queue yet. No production data should be entered; stored candidate JSON includes synthetic vendor/customer relationships and is not encrypted. A local SQLite file is not a tamper-proof boundary. No executable distribution or actual database migration authorized. Exact-revision CI required.
