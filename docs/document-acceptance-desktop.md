# Synthetic document acceptance desktop interfaces

The existing project documents window exposes the folder configuration/setup and transmittal center only in the separate synthetic document acceptance mode, for administrators. Acceptance-only public wrappers recheck the existing native service grants, session, project identity and schema. Folder interface supports reviewed existing root, template label editing, configuration revision history and registration or retirement of an existing project folder, preserving prior references. No folder creation UI or modification to existing directory contents. Transmittal center lists a bounded set of verified historical manifests and evidence events, selects current production PDF versions, and records explicit synthetic preparation/issue/delivery/withdrawal attestations. No email, document signing, automatic issue or evidence authentication. Historical listing is bounded at 100 transmittals and 256 MiB cumulative selected bytes; it fails closed rather than silently truncating. UI refresh after writes clears inputs; uncertain failure requires reconciliation. Production scope and actual professional authority remain unapproved. New native and manual desktop acceptance checks are required; do not use real project files or accounting credentials. No production release.
