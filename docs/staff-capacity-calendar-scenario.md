# Individual capacity calendar scenario (PRJ-02)

Extend the current workload review with optional individual Monday–Sunday capacity in integer minutes, firm-wide closure dates and individual dated capacity overrides. No default schedule is invented. An individual week replaces common weekday capacity, if present; otherwise employees with no schedule have unknown capacity. Firm closures are zero and cannot be overridden, individual exceptions replace normal daily capacity only with a known base schedule. Zero is valid for an unavailable day. Unknown/inactive employee numbers, duplicate entries, out-of-range dates, exceptions without base, conflicting closure/override and invalid minute amounts are rejected. Calendar input uses exact employee numbers, ISO dates and bounded multiline text, not external files. The same planning permissions apply to the full transactional read.

Original weekday task demand is intentionally unchanged by availability assumptions. This exposes demand on closed/unavailable days and excess daily minutes; it does not automatically reschedule work, infer remaining effort or move estimates onto weekends. Weekend-only task estimates remain separately unallocated, including when weekend capacity is specified. Capacity totals can include weekend availability, so totals alone must not be interpreted as staffing sufficiency. No capacity for inactive employees or unspecified schedules; held work is excluded from overload calculations. Scenario dates and rules are temporary in the desktop window and cleared on close, not persisted HR schedules, leave approvals, paid time, payroll, holiday calendars or employment policy. Actual approved calendar policy and persistence require separate owner review and design. No schema change, no production authorization. Pure and service regression tests added; interactive desktop and Windows exact-revision verification pending.
