# Task planning usability

Separate phase and task toolbars, context-dependent edit/cancel/stop/history actions, selected record retention after refresh, named project state, and explicit cancel in editors. New assignments default to the sole available phase or employee only when unambiguous; phase dates populate task defaults. Estimate inputs accept total decimal hours when exactly representable in minutes or hours:minutes, including multi-day estimates; existing estimates round-trip without changing stored values. The original service validation, work authorization, scope, optimistic revision and audit requirements remain decisive. No schema or permission change. This candidate requires exact CI and interactive WPF acceptance. Management approval interface remains unchanged.
