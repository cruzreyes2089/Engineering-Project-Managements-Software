# Durable synthetic attempt assessments — schema 28

Persist normalized simulated transport observations, source fingerprint, classifier result, independently matched synthetic GUID (if any), response GUID, actor and UTC in the same immediate transaction as the attempt transition. Immutable assessment records and SQL guards prevent a witnessed attempt advancing to confirmation or uncertainty without its evidence. Witness-stage failures remain distinct and require no fabricated response. A historical confirmation without recorded assessment cannot be reviewed under the new schema; it remains held, not silently backfilled. Read-only history exposes assessment status, HTTP status and recovery finding but not external keys, raw responses or attempt capability. All observations remain caller-supplied synthetic test facts, not proof of actual Manager dispatch or live ledger reconciliation. No retry, posting, hold release or real transaction authorization is introduced. Tests cover failure before assessment insert, immutable evidence, witnessed vs transport uncertainty and preservation of simulated confirmation history.
