# Simplified folder template selection — schema 53

The built-in neutral label is Suggested preset. The underlying CRC-Production-2 revision key remains unchanged for historical fingerprint compatibility; it is not a business identity requirement. A business can create, copy, edit and select its own templates. The preferred template is optional, explicitly chosen and cleared in the template manager. It preselects a suggestion only for unassigned project selection dialogs; no project is automatically assigned, and users can choose any saved template. Preference is exact-revision bound, audited and append-only. Changed catalog revisions require a fresh preference confirmation.

Project category recommendations are retired: no category selector, settings screen, or application service read/write path remains. Schema 52 historical rows and migration are retained, with inserts blocked in schema 53 and the existing immutable update/delete triggers unchanged. No automatic conversion of categories into a preference. Existing template, project, override and storage preference records remain untouched. No filesystem operations or production authorization.
