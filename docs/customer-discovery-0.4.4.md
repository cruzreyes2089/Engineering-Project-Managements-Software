# v0.4.4 — read-only customer schema discovery

Manager's published customer-list API documents GET /api2/customers, skip and pageSize query parameters: https://manager.readme.io/reference/getcustomers. This diagnostic requests skip=0 and pageSize=2 via the existing saved connection and the existing restricted loopback client. It reports only root field names, root value types, at most three candidate arrays, sample row counts and a bounded list of immediate row field names/types. UUID-shaped strings are classified, never printed. Field names are limited to short identifier-like names; no nested values or raw records are displayed or saved. These are structural observations, not a verified customer mapping or proof of identifier stability. Only a synthetic Manager business should be used. The sample may be empty; create synthetic customers in Manager before discovery if necessary. No customer records or transactions are written to either application. No database migration beyond schema 3. No automatic data export. Existing accounting-test permission and protected saved profile apply. Owner must provide the sanitized schema observations from the installed version before customer mapping is implemented.
