# Internal schema 47 to 48 budget migration candidate

The isolated budget branch now embeds the same tested DDL into the persistence assembly. The internal migration requires an existing initialized schema 47 and caller-owned transaction with foreign keys enabled. It compares every existing schema object and typed row value before and after, excluding only the exact new objects generated independently from the embedded DDL and the two new Administrator grants. It rejects pre-existing budget objects/grants/audits, checks empty new history and foreign keys, and returns a preservation digest before commit. A synthetic real-project integration test replaces manual table provisioning with this migration; an injected user-row mutation on grant insertion must abort the migration and roll back tables, grants and schema version. The ordinary constructor and bootstrap are deliberately unchanged; existing schema 47 remains active and 48 is not a normal startup target yet. No automatic migration, actual user files, association prototype activation, release or deployment. Windows qualification pending.
