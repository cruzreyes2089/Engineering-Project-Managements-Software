# CRC proposed project folder template

Use the user's existing folder terminology rather than numbered generic folders. Proposed defaults: Architectural, Calculations, Construction Administration, Plancheck Comment Responses, Reference Documents, Send Outs, Site Pictures, Structural DWGs. Reference Documents replaces Existing Conditions and is for available client-provided drawings, surveys, geotechnical reports and other references; it may be omitted. Construction Administration is for construction-phase RFIs, submittals and observations, not general business administration. Plancheck Comment Responses is distinct from internal QA-QC. Send Outs is the intuitive file-folder name; the application must still distinguish review preparation, recorded issue and recorded delivery, and folder presence is not evidence of issue. Correspondence and QA-QC are optional; Mechanical, Electrical and Plumbing may be selected for applicable scopes. Architectural may be omitted for structural-only projects. No assumptions about the redacted names in the screenshot.

The native candidate provides default labels and pure validation/selection preview for customized templates. It does not persist custom templates, expose a configuration UI, create folders, enumerate existing folders, rename existing folders or modify any existing filesystem. Future explicit setup must preserve existing folders and provide a reviewed non-destructive creation plan; external folder registry and durable transmittal service remain inactive. Template labels are independent of document classification and permission rules. No shared storage qualification or release authorization.
