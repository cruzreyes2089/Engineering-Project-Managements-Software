# Project workspace

The Projects register opens a selected project in one permission-aware workspace with project number, title, client, site, operational state, setup and conflict screening. Existing task, document, QA/QC, agreement/setup, contacts, conflict and closeout dialogs are reached from this single context. The register's redundant direct action buttons are removed. Double-clicking a selected project row is an alternative to Open selected project. The exact project is read by ID in an authorized transaction rather than searching a bounded register. Each child action rechecks the project and grants, and the workspace refreshes after closing it. No new business operations, schema, physical storage or posting authority. The new workspace is a navigation consolidation; existing dialogs and service validations remain intact. Interactive desktop acceptance and exact regression pending.
