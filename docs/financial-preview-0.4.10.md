# v0.4.10 — synthetic financial list preview

Live schema: invoiceAmount.value and balanceDue.value, receipt/payment amount.value are JSON numbers; currency explicitly null. The preview deliberately supports only null currency, ordinary nonnegative decimal values (up to 12 integer digits and 6 fractional digits), invoice balance not exceeding amount, complete pages of at most 20 rows each and distinct nonempty UUIDs per register. Unknown currency, invalid values, incomplete pages and mixed business names fail closed. No inferred USD, currency conversion, credit/negative/overpayment support or production totals. Decimal arithmetic only.

Requires existing marker and administrative identity/connection permissions. Reads saved profile with marker check before and after sequential GETs, rechecks session/profile/marker before returning. No raw names/IDs in preview, no persisted amounts, no Manager writes. Exact clone safety and concurrent remote changes cannot be ruled out. This is not atomic and is not full ledger reconciliation. Invoice gross total is not necessarily revenue; receipt less payment is not bank balance. Test fixture only: one invoice 100 with balance 60, one receipt 40, one payment 10, net receipt less payment 30. Compare Manager Summary independently. No schema migration from 5. Customer sync, account role mapping, document form relationships, date/currency/tax handling, posting/reconciliation remain gated.
