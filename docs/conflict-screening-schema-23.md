# Project conflict screening — schema 23

Generic, firm-configurable-by-review screening (no named employer or private owner data). Explicit jurisdiction and answers for restricted public-employer jurisdiction, public duty involvement, public resources/nonpublic information and unresolved conflicts. Unknown or Yes holds new project authorization, starting planned tasks and approving additional scope. Current review bound to accepted proposal hash, immutable history, separate view/record permissions, stale-review rejection, database triggers and service checks. Existing active projects remain historically active but cannot start new tasks without review. Already performed work may still be documented; no automatic recusal, legal conclusion, employer approval, external jurisdiction lookup or declaration generation. Reviewers must obtain evidence and assess restrictions independently; a new Clear review requires changed/verified facts, not a bypass. Proposal issuance occurs before this project gate; pre-engagement screening and restricted jurisdiction register remain separate work. No production accounting changes or executable distribution.
