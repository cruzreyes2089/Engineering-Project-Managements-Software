# Daily workload and capacity review — PRJ-02

The staff workload snapshot now contains bounded per-employee daily rows for every date in the selected inclusive range (at most 500 x 366). The selected employee's detail grid is generated from the same transactional read and same allocation as the summary; it does not independently query or recalculate a different snapshot. Shows eligible and held allocated hours, nullable capacity and excess, and the capacity basis (individual week, common weekdays, firm closure, individual override, unknown or inactive). Known zero capacity and unspecified capacity remain distinct. A toggle filters positive daily excess only; unknown capacity is not a verified conflict or a confirmed fit. The ordinary summary remains intact. Changing any scenario input clears both grids; closing the window clears the data sources. Daily and aggregate integer minutes reconcile before display rounding; weekend-only estimates are not allocated into daily totals. Demand remains original estimates rather than actual or remaining hours. Held allocations never contribute to overload. No work reassignment, actual HR calendar persistence, leave approval or payroll. The source tests exercise date, arithmetic, unknown capacity and closure cases. Native Windows and interactive desktop qualification pending; no schema change, release promotion, real data or artifact distribution.
