# Business-specific production folder templates — schema 49

Administrators with Documents.Restricted may customize production folder names and order from Staff and permissions > Business storage. The initial preset remains CRC-Production-2: nine flat folders, Reference Documents without MEP descendants, QA-QC, and optional Correspondence. The editor supports adding, removing and renaming flat labels, and loading the standard preset. Each business database retains append-only template revisions and audit entries; stale revisions are rejected and identical saves are no-ops. Project preview and storage draft rebuild the same current template, including revision in the plan fingerprint. Restricted labels and permissions remain fixed and separate; no arbitrary nested path or access-boundary changes. This is a deliberate first-release scope; nested and per-project customization can be considered later. Input is limited to 1–30 unique Windows-safe labels of up to 64 characters, excluding fixed restricted labels and Correspondence.

Changes affect logical previews only, including existing projects. No directory creation, relocation, deletion, adoption or document registration is performed. Eventual physical provisioning requires durable binding to the exact approved template and storage version; an existing physical project must not silently follow new defaults. Schema 48 upgrade starts with the standard preset without inserting a preference row. Recovery copies retain revision history without activating external storage. The one-firm-per-database architecture is unchanged. No live storage access or release authorization. Source regression pending.
