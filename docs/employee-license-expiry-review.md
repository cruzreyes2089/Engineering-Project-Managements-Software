# Firm-wide employee license expiration review (HR-01)

Current staff window previously showed expiry status only after selecting one employee. Add a read-only firm-wide review of active employees' recorded expiration dates, with as-of date and 1–90 day service horizon (15/30/60/90 desktop choices, default 30). Expired dates remain included regardless of horizon; due today is separate; future horizon inclusive. Sort by date and employee number, stable license ID tie break. No license numbers, email, account details, compensation or rates in alert projection. Existing Employees.View grant required inside the transaction; no automatic notification or external request. Inactive employees remain in existing historical employee/license screens but are excluded from current alert review. Dates are current recorded values, not an as-of reconstruction of past renewals. Invalid date or active register beyond 5000 rows fails rather than silently truncates. An employee with no license record does not appear; no assertion of required license coverage, license verification or authority to practice. Local interactive alert register only, no email reminders or delivery history. Schema unchanged. Original HR-01 and REP-01 acceptance requirements remain, no desktop scenarios marked passed. New native tests and desktop build require Windows CI; interactive acceptance and independent security approval remain pending.
