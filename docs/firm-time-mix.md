# Restricted firm time-mix report

Firm-wide per-employee approved time is reconciled into billable project work, nonbillable project work, unclassified project work and nonbillable overhead. Pending and rejected minutes are separately reported by project/overhead; expenses and attendance are excluded. All employees with activity in the range are included, including inactive historical staff. Billable share is approved billable / all approved minutes; absent when no approved time or unclassified approved minutes exist. It is not a utilization target, payroll measure, capacity metric, posted revenue or cost report. Existing financial-report and billing-classification/employee/project/client grants are required; ordinary employees cannot see the report. Date range bounded, single read transaction, per-row reconciliation. Independent firm time-mix window from Reports, no selected project needed. Tests cover exact minutes, overhead in denominator, missing classification and empty range.
