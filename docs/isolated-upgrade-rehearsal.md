# Isolated schema upgrade rehearsal — test-first specification

The existing LocalPractice constructor migrates within a SQLite transaction. A successful source-level migration test does not qualify a field upgrade or backup restoration. Rehearsal is deliberately separate: trusted closed local synthetic copy, explicit confirmation and exact independently retained SHA-256, no source mutation, no sidecar, bounded bytes, no current live database selection or automatic replacement. Copy to a newly owned private temporary directory next to the trusted source; inspect SQLite header and supported version 1–46, integrity and foreign keys, preserve baseline firm/client/contact/user identities, migrate only disposable copy using actual constructor; recheck schema, integrity, foreign keys, baseline identities and source hash. Delete owned staging files after success/failure, never delete original. Return counts and hashes, no records or credentials; do not expose a working migrated copy. Rehearsal may retain confidential data on disk if cleanup fails or process crashes, so run only on a protected synthetic copy in isolated environment. No installer execution, production authorization, network, or release of security hold. Test-first stub deliberately fails; full Windows source verification and actual desktop/installer acceptance remain separate.
