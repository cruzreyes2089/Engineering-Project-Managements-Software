# Project and firm overhead allocation scenarios

Schema-48 candidate adds read-only scenario calculations, no migration or accounting entries. Firm review is reachable through existing restricted labor-cost report and rereads approved project and overhead labor with its existing transactional permissions (including financial/rates and work/classification grants). Same-period explicit additional labor burden percentage applies only to labor cost not already burdened; other indirect cost input excludes labor and direct project costs already represented. Pool = burdened overhead labor + other indirect cost. Allocation denominator = all approved project labor hours (billable, nonbillable, unclassified), not billable hours alone. Modeled cost recovery per approved billable hour = (burdened project labor + indirect pool) / approved billable hours; suppressed if unclassified approved project time, missing rates or zero billable hours. No project expense costs included in that firm recovery measure, no revenue, actual profit, attendance or utilization inference. Missing rate anywhere suppresses complete totals and rates. Explicit zero permitted, no preset burden or overhead. No actual accounting data retrieved.
