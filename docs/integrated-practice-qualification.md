# Integrated practice qualification

A single synthetic SQLite practice exercises client/contact separation, proposal screening and acceptance, pending-start denial, reviewed agreement and authorization, setup, task estimate and time input conversion, document identity, QA/closeout blockers, three distinct authenticated accounts, independent approval/rejection and linked correction, independent billing classification, employee cost access denial, exact hourly billing and source allocation, independent draft approval, project financial reports, operational closure, recovery and isolated restore. The scenario uses the public service API; it is not a desktop click-through, installation, actual migration, or external accounting test. No live network access or accounting posting. Existing source/acceptance registers remain intact. Exact regression pending; no release authorization.
