# Approved invoice candidate comparison

An authorized operator may compare an immutable approved internal invoice draft with the existing CRC ACCOUNTING TEST synthetic business. Requires the saved profile, enrolled marker, a synchronized directory and current provisional client/customer link. Acquisition is read-only, bounded to 20 invoice records with two matching reads and marker before/after. Exact external reference, customer GUID, issue date and total must match. Multiple case-insensitive references, missing or invalid customer identity, changed context and wrong amounts fail closed. The current draft and cached link are checked again after acquisition. No matching result creates a persistent link or claims legal issuance, verified line/account/tax allocation, due date, actual payment, or an authoritative ledger balance. Provisional directory linkage is operator evidence, not verified business identity or clone detection. No production endpoint or POST request is enabled. Core comparison tests cover exact match, incorrect customer/date/amount/reference and incomplete evidence; actual desktop/provider acceptance remains pending.

Integration regression uses an existing approved local draft, synthetic loopback Manager responses, actual saved profile, marker, directory sync and provisional customer link. It checks that the match neither changes the draft nor survives removal of the provisional link, and that ordinary employees cannot invoke it. No live Manager records are changed.
