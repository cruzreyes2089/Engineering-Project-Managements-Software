# Staff administration and employee register — schema 14

Adds administrator-only account provisioning, role grant editing for non-administrator roles, forced temporary-password replacement without granting a session, password resets, deactivation and credential revision invalidation of previous sessions. Non-administrator roles start deny-by-default; existing grants preserved. Administrator role and Administration.Manage are protected from ordinary changes. No unrestricted role escalation, self-reset or administrator-recovery UI. Credentials are PBKDF2 hashes; no password exposed in lists. Existing local OS owner can still directly access the SQLite file.

Adds employee directory, optional immutable one-to-one account link, active status independent from login status, license registration and renewal, date-based 30-day expiry indications. No salary, cost or billing rate fields are included; these require separate finance authorization in a later module. The expiry display is based on local date, not a licensing-board verification or automated reminder. Fixed numbering EMP-000001 is provisional. UI and service tests added, CI pending. No live records or executable uploads.
