# Read-only synthetic witness comparison

Compares the existing caller-selected external witness scope to all local full-wire attempts (maximum 500), reconstructing the exact expected witness bytes from immutable payload and attempt identities. Reads scope and directory twice, rejects a different store or marker, reports missing, conflicting, unexpected files and unresolved attempts. Unexpected files are never opened or deleted. Existing ordinary-path checks reject reparse points. No attempt keys, raw payload, file contents or external GUIDs are returned. Comparison works during declared lifecycle holds while authorized marker evidence remains available. No mutation, new enrollment, replay, repair, posting or hold release. A perfect comparison is only evidence for review, not proof of absence of remote activity. Bounded counts are not a full report if inspection is blocked; two matching per-entry name and classification scans are not an atomic filesystem snapshot; Windows comparison requires a local fixed drive. The supplied store ID/path are not a durable independently authenticated database binding. Simultaneous restoration of both stores, local administrator tampering, race conditions and earlier legacy rehearsal history are outside this comparison. CI exercises missing, changed and orphaned synthetic files and ensures unresolved attempts remain held.
